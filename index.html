AI Settings Open
Default mode uses your local Ollama server. No OpenAI API key or paid tokens are required when using Ollama Local. For local AI, keep Ollama running at http://localhost:11434.
If the browser cannot connect to Ollama, run this in Terminal, then restart Ollama:
launchctl setenv OLLAMA_ORIGINS "*"
OpenAI mode calls OpenAI directly from the browser. It is fine for your own test, but for public staff use, move the API call to a backend proxy so your API key is not exposed.
